# 🟦 Translator - Flask Version

Google Translate-like web app built with Flask and deep-translator.

---

# ⚙️ Features

- 🌍 Multi-language translation
- 🔁 Swap languages
- 🧠 Auto language detection
- 🎨 Clean Google Translate-style UI

---

# 📦 Installation

git clone https://github.com/FefinDev/translator.git  
cd translator/flask  

pip install -r requirements.txt  

---

# 🚀 Run

python app.py  

---

# 🌐 Open in browser

http://localhost:7200  

---

# 📦 Requirements

flask  
deep-translator  

---

# 🧠 Notes

- Simpler than FastAPI version
- Great for learning Flask basics
- Uses Flask built-in static handling
